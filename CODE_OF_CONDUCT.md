# Code of Conduct

The ModeratorIM community follows one **project-wide Code of Conduct**, maintained in the main
repository. It applies to this repository, its issues, pull requests, and discussions:

➡️ **https://github.com/ModeratorIM/ModeratorIM/blob/main/CODE_OF_CONDUCT.md**

In short: participation is a harassment-free experience for everyone. Report unacceptable behavior
to the maintainers via the contact in the canonical policy above.
